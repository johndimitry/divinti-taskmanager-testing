# 🚀 DiVinti Tech - Gerenciador de Tarefas

Interface moderna estilizada com a identidade visual da **DiVinti Tech** (Preto, Vermelho e Branco), voltada ao gerenciamento de tarefas cotidiano com foco absoluto em qualidade e estabilidade de código através de testes automatizados.

## 🛠️ Tecnologias e Ferramentas
- **Frontend:** HTML5, CSS3, JavaScript puro, estruturado sobre ambiente Vite.
- **Testes Unitários:** [Jest](https://jestjs.io) para validação lógica.
- **Testes de Interface (E2E):** [Cypress](https://cypress.io) para simulação de jornada de usuário.

## 🧪 Como rodar os testes

### Testes Unitários (Jest):
```bash
npm test
```

### Testes de Interface (Cypress):
```bash
npm run cypress:open
```
